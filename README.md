# Tigershark — Premium Pools & Pavers

Marketing **landing page** for a pools & pavers business — logo, tagline, and embedded [Tally](https://tally.so) lead form.

## Stack

- React 18 + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Tally embed (client-side widget loader)

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Static Vite build → any static host (Vercel, Netlify, Lovable publish).

## Status

Single-page marketing site — not a product backend; kept in the portfolio as a **rapid UI delivery** sample.
